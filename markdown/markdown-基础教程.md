# Markdown 基础教程（新手向）

> 用途：写笔记、README、文档全靠它。
> 特点：**纯文本 + 简单符号**，任何编辑器都能打开，GitHub 原生支持。
> 最后更新：2026-10-19

---

## 一、Markdown 是什么

**一句话**：用**纯文本**写文档，用简单符号表达格式。

**对比一下**：

| 格式 | 优点 | 缺点 |
|---|---|---|
| Word（`.docx`） | 所见即所得 | 二进制文件，Git 没法比对差异 |
| **Markdown（`.md`）** | 纯文本、可读、Git 友好 | 要记几个符号 |
| HTML | 最强 | 太啰嗦，写文档累 |

**为什么程序员都用它**：
- GitHub 的 README 就是 Markdown
- 写技术文档、笔记、博客都靠它
- 用 Git 管理时，能清楚看到"改了什么"

**文件名后缀**：`.md`

---

## 二、标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

**渲染效果**：

> 一级最大，六级最小。一般文章只用 `#` 到 `###`。

⚠️ **最容易犯的错**：`#` 后面**必须有一个空格**！

```markdown
❌ #标题
✅ # 标题
```

## 三、文字格式

| 写法 | 效果 | 说明 |
|---|---|---|
| `**粗体**` | **粗体** | 两个星号 |
| `*斜体*` | *斜体* | 一个星号 |
| `***粗斜体***` | ***粗斜体*** | 三个星号 |
| `~~删除线~~` | ~~删除线~~ | 两个波浪号 |
| `` `行内代码` `` | `行内代码` | 反引号（Tab 键上方） |

**VS Code 快捷键**：

| 操作 | 快捷键 |
|---|---|
| 加粗 | `Ctrl + B` |
| 斜体 | `Ctrl + I` |

## 四、列表

### 4.1 无序列表

用 `-` 或 `*` 或 `+`（推荐用 `-`）：

```markdown
- 第一项
- 第二项
  - 缩进两个空格就是子项
  - 再来一个子项
    - 还能继续缩进
- 第三项
```

**渲染效果**：
- 第一项
- 第二项
  - 缩进两个空格就是子项
  - 再来一个子项
- 第三项

### 4.2 有序列表

数字 + 点 + 空格：

```markdown
1. 第一步
2. 第二步
3. 第三步
```

**小技巧**：数字可以全写 `1.`，Markdown 会自动编号：

```markdown
1. 第一步
1. 第二步
1. 第三步
```
渲染出来照样是 1、2、3。

### 4.3 任务列表（打勾清单）

```markdown
- [ ] 未完成的任务
- [x] 已完成的任务
```

**渲染效果**：
- [ ] 未完成的任务
- [x] 已完成的任务

**语法细节**（很重要）：
```
- [ ]     ← 减号 + 空格 + 左括号 + 空格 + 右括号
- [x]     ← 完成的是小写 x，不是大写 X
```

⚠️ **必须严格这样写**：
- `-` 后面有空格
- `[` 和 `]` 之间**未完成是一个空格，完成是一个 `x`**

## 五、链接和图片

### 5.1 链接的基础语法

```markdown
[显示的文字](链接地址)
```

**拆解**：

```
[显示的文字](链接地址)
 ↑         ↑  ↑       ↑
 方括号     圆括号
```

**例子**：
```markdown
[MDN 中文文档](https://developer.mozilla.org/zh-CN/)
```
渲染成：[MDN 中文文档](https://developer.mozilla.org/zh-CN/)

---

### 5.2 路径的三种类型（重点）

#### ① 相对路径（仓库内部推荐）

```markdown
[Git 笔记](./git/git-commands.md)
```

| 符号 | 含义 | 例子 |
|---|---|---|
| `./` | **当前目录**（可省略） | `./git/a.md` = `git/a.md` |
| `../` | **上一级目录** | `../README.md` |
| 无前缀 | 相对当前文件 | `git/a.md` |

✅ **优点**：仓库换地方（clone 到别的电脑）链接照样能用；GitHub 网页能跳转；VS Code 里 `Ctrl + 单击` 能打开

#### ② 绝对路径（网站路径）

```markdown
[笔记](/git/git-commands.md)
```

⚠️ **只在 GitHub 网页上有效**，本地 VS Code 打不开。**新手别用。**

#### ③ 完整 URL

```markdown
[笔记](https://github.com/用户名/仓库/blob/main/git/a.md)
```

✅ 任何地方都能打开
❌ 仓库改名/换账号就失效，太长不好维护

**建议**：仓库内部用相对路径，外部链接用完整 URL。

---

### 5.3 相对路径实战：`./` 和 `../` 怎么用

#### 场景 A：从根目录 README 链接到子文件夹

```
notes-repo/
├── README.md          ← 你在这里
├── git/
│   └── git-commands.md
```

```markdown
[Git 命令复习](./git/git-commands.md)
```
（`./` 可省略，写成 `git/git-commands.md` 也行）

#### 场景 B：从子文件夹链接回上一级

```
notes-repo/
├── README.md               ← 目标
└── weekly/
    └── week01.md           ← 你在这里
```

```markdown
[回到首页](../README.md)
```

#### 场景 C：从子文件夹链接到另一个子文件夹

```
notes-repo/
├── git/
│   └── git-commands.md     ← 目标
└── weekly/
    └── week01.md           ← 你在这里
```

从 `week01.md` 出发：先 `..` 回上一级，再进 `git/`

```markdown
[Git 命令复习](../git/git-commands.md)
```

#### 完整对照表（假设你在 `weekly/week01.md`）

| 想链接到 | 写法 |
|---|---|
| 同目录的 `week02.md` | `week02.md` 或 `./week02.md` |
| 上一级的 `README.md` | `../README.md` |
| 上一级 `git/` 里的文件 | `../git/git-commands.md` |
| 上一级 `markdown/` 里的文件 | `../markdown/markdown-基础教程.md` |

---

### 5.4 链接到某个标题（锚点）

想跳到笔记里的某一节：

```markdown
[跳到 Git 配置章节](./git/git-commands.md#七配置相关)
```

**锚点规则**（把标题变成 `#` 后面的部分）：

| 原标题 | 锚点写法 |
|---|---|
| `## 七、配置相关` | `#七配置相关` |
| `## 一、今天实际用过的命令（按使用顺序）` | `#一今天实际用过的命令按使用顺序` |
| `### 7.2 core.quotepath —— 中文文件名不乱码` | `#72-corequotepath--中文文件名不乱码` |

**简化规则**：
- 去掉所有标点符号（顿号、括号、冒号等）
- 空格变成 `-`
- 英文转小写
- 中文保留

⚠️ **这个规则很坑，容易写错**。**推荐做法**：在 GitHub 网页上把鼠标移到标题旁边，会浮现小链条图标，点它直接复制锚点链接。

---

### 5.5 几种特殊链接写法

#### 链接 + 悬停提示

```markdown
[MDN](https://developer.mozilla.org "MDN 官方文档")
```
鼠标悬停会显示 `MDN 官方文档`。

#### 引用式链接（长文档好用）

先定义，再引用：

```markdown
我常看 [MDN][1] 和 [JS 教程][2]。

[1]: https://developer.mozilla.org
[2]: https://zh.javascript.info
```

✅ 优点：正文里链接不打断阅读，适合链接很多的文档。

#### 图片链接（点图片跳转）

```markdown
[![图片说明](./assets/logo.png)](https://example.com)
```

**拆解**：
- 外层 `[...](...)` = 链接
- 内层 `![...](...)` = 图片

**效果**：点图片会跳到指定网址。

---

### 5.6 图片

```markdown
![图片说明](图片路径.png)
```

**和链接的区别**：图片前面多一个 `!`（感叹号）

**例子**：
```markdown
![我的截图](./assets/screenshot.png)
```

**图片路径写法**（和链接完全一样）：

| 类型 | 写法 | 说明 |
|---|---|---|
| 相对路径 | `./assets/a.png` | ✅ 推荐，跟着仓库走 |
| 上级目录 | `../assets/a.png` | |
| 网络图片 | `https://xxx.com/a.png` | 依赖网络 |
| 绝对路径 | `D:\code\a.png` | ❌ 不要用，别人打不开 |

**建议**：在仓库里建个 `assets/` 或 `images/` 文件夹放图片，用相对路径引用。

**注意**：GitHub 上图片大小建议控制在 1MB 以内，太大的图会加载很慢。

### 5.7 VS Code 里的链接技巧

#### ① 自动补全路径

在 VS Code 里写 `[...](` 之后，会**自动弹出文件列表**，选中即可自动填好路径。

#### ② Ctrl + 单击跳转

写好链接后，按住 **`Ctrl`** 点链接，会直接打开那个文件。

**验证链接对不对**：`Ctrl + 单击`，能打开就是对的。

#### ③ 拖拽文件自动生成链接

1. 选中一段文字
2. **按住 `Shift` 拖拽**一个文件到编辑器里
3. 自动生成 `[文字](路径)`

### 5.8 链接的常见错误

| 错误写法 | 问题 | 正确写法 |
|---|---|---|
| `[文字](git\git-commands.md)` | 用了**反斜杠** | `[文字](git/git-commands.md)` |
| `[文字](D:\notes-repo\git\a.md)` | **绝对路径** | 用相对路径 |
| `[文字](.git/a.md)` | 少了一个 `/` | `./git/a.md` |
| `[文字](git/a.md)` 但文件不在这 | 路径错 | 检查文件实际位置 |

**最重要的一条**：**路径用正斜杠 `/`，不要用反斜杠 `\`**

虽然在 Windows 上文件系统用 `\`，但 Markdown 链接**必须用 `/`**。

### 5.9 一句话总结

```markdown
[显示文字](路径或网址)
```

**路径规则**：
- 同目录：`文件名.md`
- 子目录：`文件夹/文件名.md`
- 上一级：`../文件名.md`
- 外部网站：`https://...`

**记住 `./` 是当前、`../` 是上一级，就够了** (๑•̀ㅂ•́)✧

## 六、代码块（程序员最常用）

### 6.1 行内代码

用**一个反引号**包起来：

```markdown
运行 `npm install` 安装依赖
```

渲染：运行 `npm install` 安装依赖

**用途**：提到命令、文件名、变量名时用。

### 6.2 多行代码块

用**三个反引号**包起来：

````markdown
```js

```
````

**渲染效果**：

```js
console.log("Hello World")
```

**关键技巧**：三个反引号后面写语言名，代码会按该语言高亮显示。

| 语言 | 写法 |
|---|---|
| JavaScript | ` ```js ` |
| TypeScript | ` ```ts ` |
| HTML | ` ```html ` |
| CSS | ` ```css ` |
| Python | ` ```python ` |
| Java | ` ```java ` |
| C | ` ```c ` |
| C++ | ` ```cpp ` |
| PowerShell | ` ```powershell ` |
| Bash / Shell | ` ```bash ` |
| JSON | ` ```json ` |
| SQL | ` ```sql ` |
| Markdown | ` ```markdown ` |

**例子**：

## 八、表格

### 8.1 基础表格

```markdown
| 姓名 | 年龄 | 城市 |
|---|---|---|
| 小明 | 18 | 北京 |
| 小红 | 20 | 上海 |
```

**渲染效果**：

| 姓名 | 年龄 | 城市 |
|---|---|---|
| 小明 | 18 | 北京 |
| 小红 | 20 | 上海 |

**语法要点**：
- 第一行是表头
- 第二行是分隔行（`|---|---|---|`），必须有
- 后面的行是数据

### 8.2 对齐方式

第二行的冒号控制对齐：

```markdown
| 左对齐 | 居中 | 右对齐 |
|:---|:---:|---:|
| a | b | c |
| 长一点的内容 | 长一点 | 长一点 |
```

**规则**：
- `:---` → 左对齐
- `:---:` → 居中
- `---:` → 右对齐

### 8.3 VS Code 里的表格技巧

- 打完 `| a | b |` 后按 **`Tab`**，会自动补全表格结构
- 表格对齐乱了，可以装 **Markdown All in One** 扩展，有"格式化表格"命令

## 十、换行（新手第一大坑）

### 问题：单个回车不换行

```markdown
第一行
第二行
```

**渲染出来是**：第一行 第二行（连在一起了！）

### 三种解决办法

**方法 A：行末加两个空格**

```markdown
第一行··
第二行
```
（`·` 代表空格，行末真的敲两个空格再回车）

**方法 B：空一行（变成新段落）**

```markdown
第一行

第二行
```
这个最常用，而且看起来更清爽。

**方法 C：用 `<br>` 标签**

```markdown
第一行<br>第二行
```
Markdown 支持内嵌 HTML，`<br>` 就是强制换行。

**建议**：日常用**方法 B**（空一行），想要紧凑排版用**方法 C**。

## 十四、打勾清单（`- [ ]`）的完整说明

### 14.1 为什么在编辑器里"点不了"

`- [ ]` 本质是**纯文本**，就是三个字符：左方括号、空格、右方括号。

**它本身不是可点击的复选框**，要靠编辑器渲染成复选框才行。

### 14.2 四种让它可以"打勾"的方式

| 方式 | 怎么用 | 能否点击 |
|---|---|---|
| **手动改文本** | 把 `[ ]` 改成 `[x]` | ❌ 但永远可用 |
| **VS Code 预览** | `Ctrl + Shift + V` | ❌ 只读预览 |
| **Markdown Checkbox 扩展** | 装扩展后 `Ctrl + 单击` | ✅ **推荐** |
| **GitHub 网页** | 推到 GitHub 后看 | ✅ 能点（但会生成 commit） |

### 14.3 最实用的做法

**日常写笔记**：
1. 用 `- [ ]` 写待办
2. 做完了**手动**把 `[ ]` 改成 `[x]`（选中空格打 `x` 就行）
3. 想看渲染效果按 `Ctrl + Shift + V`

**想要点击体验**：
装 `bierner.markdown-checkbox`，然后在 `- [ ]` 那行 `Ctrl + 单击`。

### 14.4 语法检查清单

正确的写法：
```markdown
- [ ] 未完成
- [x] 已完成
```

常见的错误：
```markdown
❌ -[] 未完成         （减号和括号之间没空格）
❌ - [  ] 未完成      （括号里有两个空格）
❌ - [X] 已完成       （大写 X 不识别）
❌ * [ ] 未完成       （星号虽然也行，但统一用减号更清晰）
```
