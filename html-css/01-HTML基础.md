## HTML 文件骨架（要背下来）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>页面标题</title>
</head>
<body>
    页面内容
</body>
</html>
```

**以后每个 HTML 文件都是这个结构，一字不差。**

---

## 逐行解释

| 代码 | 作用 | 必记 |
|---|---|---|
| `<!DOCTYPE html>` | 声明这是 HTML5 文档。不写浏览器会进「怪异模式」 | ✅ 第一行固定 |
| `<html lang="zh-CN">` | 根元素，`lang` 声明页面语言是简体中文 | ✅ |
| `<head>` | **给浏览器看的信息**，不显示在页面上 | ✅ 重点 |
| `<meta charset="UTF-8">` | 字符编码声明 | ✅ 必写 |
| `<title>` | 浏览器标签页标题 | ✅ |
| `<body>` | **给用户看的内容**，页面上显示的都在这 | ✅ 重点 |
| `<h1>` ~ `<h6>` | 六级标题，数字越大字越小 | ✅ |
| `<p>` | 段落（paragraph） | ✅ |

---

## 一句话记忆

> **头里放信息，身上放内容。**
> `<head>` 看不见，`<body>` 看得见。

---

## 两个最容易混的概念

### ① `<head>` vs `<body>`

| | `<head>` | `<body>` |
|---|---|---|
| 给谁看 | 浏览器 | 用户 |
| 显示吗 | ❌ **不显示** | ✅ **显示** |
| 放什么 | 编码、标题、引入 CSS/JS | 页面上所有内容 |

**实验验证**：把 `<h1>` 放进 `<head>` 里 → 内容消失了。证明 head 里的东西不显示。

### ② `<title>` vs `<h1>`

| | `<title>` | `<h1>` |
|---|---|---|
| 显示位置 | 浏览器**标签页** | **页面内容** |
| 数量 | 一个 | 建议一个 |
| 作用 | 标识整个页面 | 页面主标题 |
| 搜索引擎 | 用作搜索结果的标题 | 用作内容权重 |

**实验验证**：改 `<title>` → 只有标签页变，页面内容不变。

## 标签的两种类型

### 成对标签（大部分）

有开始和结束，中间包内容：

```html
<p>段落内容</p>
<h1>标题</h1>
<div>块级容器</div>
<a href="#">链接</a>
```

**规则**：结束标签比开始标签多一个 `/`

### 自闭合标签（少数）

没有结束标签，单独一个就完整：

```html
<meta charset="UTF-8">
<img src="photo.jpg" alt="图片">
<br>
<input type="text">
<hr>
```

**记法**：这类标签**不能包内容**，所以不需要结束标签。

## 文件命名规范

| 规则 | 说明 | 例子 |
|---|---|---|
| **首页固定叫 `index.html`** | 服务器默认找它 | `index.html` |
| **全小写** | 避免大小写问题（Linux 区分大小写） | `about.html` |
| **用 `-` 连接单词** | 不用空格、下划线 | `my-page.html` ✅<br>`my page.html` ❌ |
| **不用中文名** | 部署时容易出问题 | `about.html` ✅<br>`关于.html` ❌ |

## 实验记录（重点：结论要准确）

### 实验 1：删掉编码声明

**操作**：删掉 `<meta charset="UTF-8">`，保存刷新

**实际结果**：⚠️ **没有乱码！**

**为什么**：现代浏览器有「自动编码检测」功能，会猜出文件是 UTF-8。

**但这不是说不用写**，原因：

1. 浏览器「猜」可能猜错（尤其文件里有混合编码时）
2. 旧浏览器（IE）不会猜
3. 服务器返回错误 `Content-Type` 时依然会乱码
4. 明确声明才能保证 100% 正确
5. 搜索引擎、屏幕阅读器依赖它

**补充验证**：把文件用 **GBK 编码**保存，再刷新 → **真的乱码了**

```
<h1>鎴戞槸Deepseek椴搁奔濞樼殑涓讳汉!!!</h1>
```

**原因**：文件是 GBK 编码，浏览器按 UTF-8 读 → 对不上 → 乱码

**结论**：`<meta charset="UTF-8">` **必须写**，它保证「不靠猜」。

---

### 实验 2：改标题级别

**操作**：把 `<h1>` 改成 `<h2>`、`<h3>`... 每次保存刷新

**结果**：字号依次变小 ✅

**理解**：`h1` 到 `h6` 是六级标题，`h1` 最大，`h6` 最小

**规范**：
- 一个页面**只用一个 `<h1>`**
- 标题**按层级使用**，不要跳级（h1 直接到 h4 是错的）

---

### 实验 3：改 title

**操作**：改 `<title>` 的内容

**结果**：只有浏览器标签页变了，**页面内容没变** ✅

**理解**：`<title>` 只影响浏览器 UI，不影响页面显示

---

### 实验 4：把内容移进 head

**操作**：把 `<h1>` 移到 `<head>` 里

**结果**：`<h1>` 消失了 ✅

**理解**：`<head>` 里的内容不显示在页面上 —— 这就是为什么内容必须放 `<body>`

## F12 看到的不是源代码（重要概念）

**浏览器做的事**：

```
你写的 HTML 文件  →  浏览器解析  →  DOM 树（F12 看到的）
     源码                          解析后的结构
```

**两者不完全一样**，浏览器会：

| 行为 | 例子 |
|---|---|
| 补全你没写的标签 | 自动加 `<tbody>`、`<head>` |
| 修正语法错误 | 你少写 `>`，它会自动补 |
| 整理成树形结构 | 按嵌套关系排列 |

**这个认知很重要**：以后调 CSS 全靠 F12，你要知道它显示的是**解析后的结果**。

### F12 实用操作

| 操作 | 方法 |
|---|---|
| 打开开发者工具 | `F12` 或右键 → 检查 |
| 用鼠标选元素 | 点左上角箭头，或 `Ctrl + Shift + C` |
| 临时改页面内容 | 双击文字直接编辑（刷新就恢复） |
| 看元素盒子 | 点元素 → 右侧看 Computed / Layout |

### ① HTML 文件骨架（要背）

    <meta charset="UTF-8">

### ② head 和 body 的区别

### ③ 编码声明必须写

```html
<meta charset="UTF-8">
```

不写「可能」不乱码（现代浏览器会猜），但**必须写**才可靠。

## 遇到问题怎么办

| 问题 | 排查方向 |
|---|---|
| 中文乱码 | ①检查 `<meta charset="UTF-8">` ②检查文件实际编码（VS Code 右下角） |
| 页面空白 | 内容是否在 `<body>` 里？ |
| 显示成源码 | 文件名后缀是不是 `.html`？ |
| Live Server 右键没选项 | ①右键的是**文件**不是文件夹 ②文件是 `.html` ③`Ctrl+Shift+P` 输入 Reload Window |
| F12 看不到元素 | ①地址栏是不是打开对了 ②面板选的是 Elements 吗 ③展开 `<html>` 小三角 |
| 改了代码没变化 | 保存了吗（`Ctrl + S`）？浏览器刷新了吗（`F5`）？ |
