## 🗂 仓库结构

```
notes-repo/
├── README.md                    ← 你在这里（总目录）
├── .gitignore                   ← Git 忽略清单
│
├── git-learn/                   ← Git 相关笔记
│   └── git-commands.md
│
├── markdown-learn/              ← Markdown 相关笔记
│   ├── markdown-基础教程.md
│   ├── markdown-day8day9练习.md
│   └── day9凌晨失眠生病.md
│
├── html-css/                    ← HTML + CSS 笔记
│   ├── 01-HTML基础.md
│   └── weekly/
│       └── week01.md
│
├── python-notes/                ← 🐍 Python 笔记
│   └── Day01-笔记模板.md
│
└── assets/                      ← 图片资源（截图、示意图）
```

**以后新增笔记的规则**：
- 学新主题 → 建新文件夹（如 `html-css/`、`javascript/`、`python-notes/`）
- 每周复盘 → 放进对应主题的 `weekly/` 下，命名 `week02.md`、`week03.md`
- 图片截图 → 放进 `assets/`
- 笔记名统一用 `DayXX-主题.md` 格式，方便按顺序排
