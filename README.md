## 🗂 仓库结构

```
notes-repo/
├── README.md                    ← 你在这里（总目录）
├── .gitignore                   ← Git 忽略清单
│
├── git/                         ← Git 相关笔记
│   └── git-commands.md
│
├── markdown/                    ← Markdown 相关笔记
│   └── markdown-基础教程.md
│
├── weekly/                      ← 每周复盘
│   └── week01.md
│
└── assets/                      ← 图片资源（截图、示意图）
```

**以后新增笔记的规则**：
- 学新主题 → 建新文件夹（如 `html-css/`、`javascript/`）
- 每周复盘 → 放进 `weekly/`，命名 `week02.md`、`week03.md`
- 图片截图 → 放进 `assets/`
