## 二、必背规则（7 条）

1. 文字必须加引号 —— `print("你好")` ✅ / `print(你好)` ❌
2. 打印变量不加引号 —— `print(name)` 打印值；`print("name")` 打印单词
3. `=` 是赋值不是等于 —— 「把右边装进左边」
4. 变量名规则 —— 字母/数字/下划线，不能数字开头，区分大小写，不用关键字
5. `input()` 拿到的永远是字符串 —— 要当数字用必须 `int()`
6. Python 对缩进严格 —— 行首不能乱加空格
7. `#` 是注释 —— 写给人看，程序不执行

## 三、必背报错（4 个）

| 报错 | 中文意思 | 常见原因 |
|---|---|---|
| `SyntaxError` | 语法错误 | 括号/引号没配对，混了中文标点 |
| `NameError` | 名字未定义 | 变量名拼错、文字忘加引号 |
| `TypeError` | 类型错误 | 字符串和数字混着算 |
| `IndentationError` | 缩进错误 | 行首多了/少了空格 |

**读报错口诀**：从下往上读 → 先看类型 → 再看行号 → 再看箭头 `^^^^`
